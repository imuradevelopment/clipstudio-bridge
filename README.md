# clipstudio-bridge

クリスタ（CLIP STUDIO PAINT）をAIエージェントが手足のように扱えるようにするためのシステム。

## 目標

エージェントが次の循環を、クリスタの全画面操作を含めて自律的に回せるようにする。

> 盤面（キャンバスの現在状態）を正確に読む → 判断する → ストロークを描き込む → 再び読む

## アーキテクチャ（確定）

```
脳（AIエージェント）
──────────────────────────────────────
① セッション層   クリスタの起動・終了・画面状態の管理
② 盤面層         ドキュメント座標系＋フレームバッファ読み取り＋キャリブレーション
③ 筆層           ストローク定義 → サンプル列コンパイラ → 仮想ペンタブ → OTD → クリスタ
④ 土台           仮想モニタ / 仮想ペンタブ(vmulti) / OpenTabletDriver
```

## 設計方針

- **脳と手足の分離**: 判断・意図はすべてエージェント（脳）が担う。プログラム（手足）は機械的に忠実であることを良しとする。人間らしさ等の創作的性質はプログラムに固定せず、その都度エージェントが入力として与える
- **読みと書きの同一座標系**: 仮想モニタのフレームバッファ（読み）とペン注入（書き）が同じ座標空間に乗るため、盤面は座標ズレのない正確なものになる
- **実績部品の組み合わせ**: 仮想ペン・仮想モニタ・タブレットドライバは実績のあるOSS（vmulti / VirtualDisplayDriver / OpenTabletDriver）を正規の使い方で利用し、自作はストロークコンパイラとセッション・盤面の管理コードに最小限限定する
- **バージョン固定運用**: 依存OSSは動作確認したバージョンに固定し、勝手な更新で壊れないようにする
