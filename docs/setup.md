# セットアップ手順（個別インストールと単体検証）

原則: **部品を混ぜない**。一つインストールしたら、その場で単体の動作を検証してから次へ進む。
本書は再現手順書であり、実施結果もここに記録していく。

## 共通の前提

- OS: Windows 11
- ドライバ類のインストールには管理者権限（UAC承認）を要する
- 取得元は全て公式のGitHubリリースとし、取得したバージョンを本書に記録する
- 検証は次の部品に進む前に行い、結果を本書に残す
