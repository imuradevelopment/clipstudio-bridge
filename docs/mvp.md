# MVP

このリポジトリのスコープ（README）の第一段階として実現したい動作。実現手段の設計は [design.md](design.md) に記す。

## MVPの目的

クリスタ（絵を描くツール）の操作を成立させるための第一歩として下記を実現すること

実現したい動作の核：
AIエージェントがキャンバスの現在状態（盤面）の内容を認識できる
↓
 AIエージェントが任意の情報（このような線を書くなどの情報）を自作システム経由で盤面に送信して反映できる
↓
AIエージェントがキャンバスの現在状態（更新された盤面）の内容を認識できる

最低限の周辺操作：
下記の最低限の一連区間の操作を
「起動〜キャンバス作成〜実現したい動作の核〜キャンバス保存〜終了」
状態を認識し正しく扱いながら操作できる
