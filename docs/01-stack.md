# 使用する部品の全リスト

状態の意味: **確定** = 本システムで使用する部品として決定済み。**設計中** = 自作する予定のもの（仕様策定中）。**実験待ち** = 実験で決める事項。

## 対象アプリ

| 部品 | 役割 | 状態 |
|---|---|---|
| CLIP STUDIO PAINT | 操作対象。ペン入力を受け付けキャンバスに描画する | 確定 |

## 仮想液タブの土台（④）

液タブ＝「ペン（書く役）」＋「画面（見る役）」。以下の三つで構成する。

| 部品 | 役割 | 状態 |
|---|---|---|
| OpenTabletDriver（OTD） | ニセペンタブからの報告を公式パイプラインで処理し、Windowsのペン入力へ変換する。GUIでペン入力の流れを可視化できる | 確定（バージョン固定運用） |
| vmulti（VirtualDrivers） | ニセペンタブ装置。仮想HIDデジタイザとして「本物のペンタブが刺さった」状態を作り、OTDの入力源になる | 確定（ドライバ導入が必要） |
| VirtualDisplayDriver（VirtualDrivers） | 仮想モニタ。液タブの「画面」役。盤面の座標系を提供し、フレームバッファを読み取り可能にする | 確定（ドライバ導入が必要） |

## 自作システム（clipstudio-bridge 本体）

| 層 | 役割 | 状態 |
|---|---|---|
| ① セッション層 | クリスタの起動・終了・画面状態の判定・遷移・ダイアログ処理。筆を撃つ前に「正規のキャンバス状態」を用意する | 設計中 |
| ② 盤面層 | ドキュメント座標系の定義、仮想モニタのフレームバッファ読み取り、キャリブレーション（既知点注入→実測→変換式確定） | 設計中 |
| ③ 筆層（ストロークコンパイラ） | ストローク定義（中間表現）を受け取り、位置・筆圧・時刻つきのサンプル列（毎秒約200回）に展開し、vmultiへ書き込む | 設計中 |

- 実装言語: C#（Windows内蔵コンパイラ csc でビルド可能。OTDのタブレット定義JSON・報告形式の参考実装もC#で存在するため）

## 補助ツール

| 部品 | 役割 | 状態 |
|---|---|---|
| ZCode ComputerUse（純正プラグイン） | セッション層でのUI操作、UIAによるUI状態（ツール・色・レイヤー等）の読み取り | 確定 |
| ペンイベント検証器（受信ロガー） | ブリッジの出力する報告列が正しい形かを、クリスタに通す前に検証する | 設計中 |

## 実験待ち（未確定事項）

| 項目 | 内容 |
|---|---|
| クリスタのタブレットAPI設定 | クリスタがWindows Ink経由のペン（筆圧つき）を受理するか。受理しない場合の設定変更手順を確定する |
| 依存OSSのバージョン固定値 | OTD / vmulti / VirtualDisplayDriver の動作確認済みバージョンを決め、READMEに明記する |
| キャリブレーション手順 | 既知点の数・配置、実測方法、変換式の求解手順を確定する |
| 代替ペン経路 | Windows標準API `InjectSyntheticPointerInput`（ドライバ不要の合成ペン注入）。本経路（vmulti＋OTD）に問題があった場合の代替として温存 |
| 速度依存ブラシの挙動 | サンプル列の時間間隔がクリスタの速度依存描写にどう影響するかの確認 |
